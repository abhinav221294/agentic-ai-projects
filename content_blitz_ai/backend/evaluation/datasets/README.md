# Content Blitz AI — Evaluation Dataset

This is a behavioral evaluation dataset, separate from the project's unit/integration tests.

## Layers
1. Intent classification
2. Research decision
3. Tool calling
4. Agent routing
5. LLM output validation
6. Research quality
7. Strategy quality
8. Content quality
9. End-to-end workflow

## Important
This is v0.1. "All possible cases" cannot literally be enumerated. The design intentionally supports continuous expansion with normal, ambiguous, edge, invalid, adversarial, and failure cases.
